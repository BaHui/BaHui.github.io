justify-content 应用

1. 理解 justify-content 的主轴方向

justify-content 主要控制子元素在主轴方向上的对齐方式。主轴方向的具体走向由 flex-direction 属性决定：

  • row（默认）：主轴为水平方向，从左到右。
  • row-reverse：主轴为水平方向，从右到左。
  • column：主轴为垂直方向，从上到下。
  • column-reverse：主轴为垂直方向，从下到上。

2. justify-content 的常见值

2.1 flex-start

  • 描述：子元素对齐到主轴的起始位置。
  • 效果：常用于导航栏布局，子元素左对齐或顶部对齐。
  • 场景：
    • 导航栏按钮左对齐。
    • 工具栏内容顶部对齐。

2.2 flex-end

  • **描述**：子元素对齐到主轴的结束位置。
  • **效果**：常用于将子元素右对齐或底部对齐。
  • **场景**：
    • 工具栏按钮右对齐。
    • 模态框关闭按钮右上角对齐。

2.3 center

  • **描述**：子元素在主轴方向上居中对齐。
  • **效果**：常用于标题、按钮组等居中显示。
  • **场景**：
    • 页面标题居中。
    • 按钮组水平居中。

2.4 space-between

  • **描述**：子元素均匀分布，首尾元素分别贴住主轴两端。
  • **效果**：常用于导航栏或工具栏等均匀分布场景。
  • **场景**：
    • 导航栏按钮均匀分布。
    • 产品展示图均匀排列。

2.5 space-around

  • **描述**：子元素周围均匀分布，首尾元素与边缘间距为中间间距的一半。
  • **效果**：适合间距需要均匀分布且边缘更紧凑的场景。
  • **场景**：
    • 按钮组需要间距均匀分布。
    • 工具栏图标间距均匀。

2.6 space-evenly

  • **描述**：子元素均匀分布，首尾元素与边缘间距与中间间距相等。
  • **效果**：更紧凑的均匀分布。
  • **场景**：
    • 按钮组间距紧凑且均匀。
    • 工具栏图标间距紧凑。

2.7 stretch

  • **描述**：子元素在主轴方向上拉伸以填满容器。
  • **效果**：常用于卡片布局或填充整个父容器。
  • **场景**：
    • 卡片布局中子元素填满父容器。
    • 填充整个父容器的表单字段。

2.8 inherit

  • **描述**：继承父元素的 justify-content 值。
  • **效果**：适用于子容器需要遵循父容器对齐方式的场景。
  • **场景**：
    • 嵌套布局中保持一致的对齐方式。

3. 场景举例

    1. 水平方向上面A和B两个div, 布局要求:
      1. 水平方向没有宽度限制, 两个div内均为文本;
      1. 水平方向上面布局均不换行, B div优先显示完, Adiv内容可以被压缩, 显示…
.container {
  display: flex;
  width: 100%;
  white-space: nowrap; // 防止内容换行
}

.div1 {
  overflow: hidden; // 溢出内容隐藏
  text-overflow: ellipsis; // 显示省略号
  white-space: nowrap; // 防止单词换行
  flex: 1;
}

.div2 {
  flex-shrink: 0; // 防止 B div 被压缩
  margin-left: 4px;
}
